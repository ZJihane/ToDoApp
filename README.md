## Overview
ToDoApp is an Android application developed in Java that helps users efficiently manage their tasks. The app provides a user-friendly interface for creating, editing, deleting, and organizing tasks to enhance productivity.

## Features
- Create, edit, and delete tasks
- Categorize tasks for better organization
- Mark tasks as completed
- Intuitive navigation for a seamless user experience

## Technologies Used
- Java
- Android SDK

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/ZJihane/ToDoApp.git
2. Open the project in Android Studio.
3. Build and run the application on an emulator or physical device.

   
##Usage
Launch the application to start managing your tasks. Easily add new tasks, edit existing ones, and track your progress.
